# AI session transcripts

AI coding tools are welcome. Save your conversations here so we can discuss your workflow, including prompts, tool output where available, corrections, and how you checked the result. We evaluate judgment and understanding, not whether you had a flawless session or used a particular tool.

- Use your tool’s built-in export when available.
- Otherwise paste the conversation into Markdown or save terminal output as text.
- Name files in reading order, for example `01-planning.md`, `02-implementation.md`.
- Include your own prompts as well as the agent’s responses. Do not reconstruct an idealized conversation afterward.
- Redact credentials, personal information, and unrelated work. Mark redactions and explain them. Do not commit your entire machine’s agent history.
- If you do not use an AI tool, say so in `DECISIONS.md`; no transcript is required.

Keep the repository and transcripts private. The starter does not record your screen or collect prompts automatically.
